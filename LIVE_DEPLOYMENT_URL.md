## 2. Local Unified Server & Dev Server
- **Unified Production Server (Client + API on Port 5000)**: `http://localhost:5000`
- **Vite Client Dev Server**: `http://localhost:5173`

## 3. Demo Access & Evaluation
Demo accounts for all 5 roles (ASHA, Doctor, Hospital Staff, Patient, Health Department Administrator) can be accessed directly on the live website via **1-Click Quick Demo Login** buttons on the login page, or credentials are provided separately for evaluation.

## 4. Cloud Deployment Architecture
- `render.yaml` for automated full-stack backend deployment on Render.
- `vercel.json` for automated frontend static asset deployment with SPA routing on Vercel.
